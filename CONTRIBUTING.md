# Contributing to StudentHub

Thank you for considering a contribution.

## Before you start

1. Read the README and current roadmap.
2. Search existing issues to avoid duplicate work.
3. For a significant feature, open or comment on an issue before coding.
4. Ask to be assigned before beginning work on an issue.

## Local setup

StudentHub currently uses plain HTML, CSS, and JavaScript.

1. Fork the repository.
2. Clone your fork.
3. Open the folder in your editor.
4. Open `index.html` in a browser or use VS Code Live Server.

There is currently no package manager, build process, or test suite.

## Pull request expectations

- Keep each pull request focused on one issue.
- Explain what changed and why.
- Include screenshots for visible interface changes.
- Test the change in a modern browser.
- Check keyboard access and mobile layouts where relevant.
- Do not commit generated files, secrets, or unrelated formatting changes.
- Link the issue your pull request addresses (for example, `Closes #12`).

## Code conventions

- Use semantic HTML elements.
- Use clear, descriptive JavaScript names.
- Prefer small functions and avoid unnecessary dependencies.
- Use CSS variables for shared design values.
- Avoid adding frameworks or libraries without discussing the reason in an issue.

## Questions

If an issue is unclear, ask for clarification in the issue before making assumptions. Be respectful and constructive in reviews and discussions.
