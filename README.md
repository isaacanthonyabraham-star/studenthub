# StudentHub

StudentHub is an open-source academic organisation platform designed to help students keep their semester organised in one place.

## Current status

StudentHub is at the **early MVP stage**. The current starter build is a responsive, client-side dashboard using HTML, CSS, and vanilla JavaScript. It is a foundation for contributors, not a finished academic management system.

## MVP direction

- Dashboard with a useful overview of a student's academic workload.
- Course list and course organisation.
- Weekly timetable.
- Assignment and deadline tracking.
- Announcements and learning resources.

## Run locally

1. Clone this repository:
   ```bash
   git clone https://github.com/isaacanthonyabraham-star/studenthub.git
   ```
2. Open the project folder.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

No build step or package installation is required for the current version.
